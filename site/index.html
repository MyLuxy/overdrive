Features

Everything you need, on the big screen.

Built for the controller: L1/R1 switch sections, ✕ selects, ○ goes back.

4,143 games

Ratings, picks, filters and sorting by score and size. See how much space a game needs before you download it.

Downloads to the console

To internal storage or a USB drive, with live speed and storage stats. A queue that recovers after a failure.

Search and favorites

Search with an on-screen keyboard, query history and a favorites page for the games you are waiting for.

Files under control

The Files page shows what is on your drives and helps you free up space.

Self-updating

A new version installs right from the console. No PC needed: the app tells you about the update itself.

19 languages

From Russian and English to Japanese, Arabic, Hindi and Bengali. New strings are added to every locale.

Install

Four steps to your first launch.

You need a jailbroken console and ShadowMount+, which installs .exfat files by itself.

01

Download the file

Get Overdrive.exfat from the latest release. Don't unzip it and don't change the extension.

02

Copy it to USB

Create a homebrew folder at the top level of the drive (exFAT) and copy the file into it.

03

Plug it into the PS5

ShadowMount+ finds the file, mounts and installs it. You get a notification; there is nothing to click.

04

Launch

Open Overdrive from the home screen. Updates arrive by themselves from then on.

USB drive
└── homebrew
    └── Overdrive.exfat

Important. The file must be named Overdrive.exfat and sit in the homebrew folder at the top level of the drive. If the app doesn't show up, the FAQ below tells you what to check.

Themes

Your own palette, one JSON file.

A theme is 12 colors and, optionally, a wallpaper. Download a ready one, put the file in a folder on the console and pick it in settings. Or build your own in the editor, which runs in the browser with no internet.

  • Applies without a restart, under Settings → Appearance → Themes
  • Built-in WCAG contrast check so text stays readable
  • Wallpaper by URL: a single file, no extra attachments

Source code

Build it yourself in a few commands.

Overdrive is a React app on top of ps5-react. It runs in a window on your PC, rebuilds on every save and builds for the console.

Terminal
# clone and set up (once)
$ git clone https://github.com/Stintik-123/Overdrive.git
$ cd Overdrive
$ npm run setup

# run in a window on your PC, rebuilt on every save
$ npm run dev
CommandWhat it does
npm run setupInstalls every dependency, once
npm run devA window on your PC, rebuilt on every save
npm testThe framework's checks
npm run buildThe PS5 app, Overdrive.exfat and update.zip

Repository layout

app/ — the application: interface, state, catalog and assets. ps5-react/ — the framework. packaging/ — building the exFAT image. docs/ — documentation, including themes.

FAQ

Frequently asked questions.

Overdrive didn't show up on the home screen

Check that ShadowMount+ is running, the folder is named exactly homebrew and sits at the top level of the drive, and the file ends in .exfat. ShadowMount+ waits until the file has finished copying.

The page won't load

The copy on the console is damaged, usually from copying through USB. Delete Overdrive.exfat, download it again and transfer it with PS5Upload. Its size on the console must match the downloaded file.

How to update

The app offers the update by itself a few seconds after it starts. Installing needs about 600 MB free on the drive that holds Overdrive.

How to remove it

First delete Overdrive.exfat from the homebrew folder, then the icon from the home screen. In the other order ShadowMount+ brings the icon back.
