Install

How to apply a theme.

01

Download the JSON

Press “Download .json” on the theme you like. The file is named after the theme, for example arctic.json.

02

Put it on the console

Copy the file into /data/overdrive/themes/. The folder is created on first use, or you can create it yourself. Transfer it over FTP or a file manager.

03

Pick the theme

In Overdrive, open Settings → Appearance → Themes and choose it under “From your themes folder”. It applies instantly.

Format

What's inside the file.

A theme is not CSS. It recolors interface elements through a shared colors module and can add a wallpaper behind everything.

arctic.json
{
  "name": "Arctic",
  "colors": {
    "canvas": "#060a10",
    "surface": "#111820",
    "fg": "#eaf4ff",
    …
  },
  "background": "",
  "backgroundDim": 0.28
}

You can set just the colors you need: the rest fall back to the base palette.

canvasThe screen behind everything, the wallpaper's dim layer
surfaceCards, tiles, dialogs, the side panel
surface2Focused rows, pressed tiles
surface3Bars, wells, deep chip backgrounds
lineDialog and card borders
fgMain text, focus ring, primary button
mutedSecondary labels and hints
subtleTertiary text, section headers
accentFgText on fg and on the status chips
okSuccess chips
warnAttention chips
infoNeutral info chips

Editor

Build your own theme.

Open full screen

The editor runs right in the browser, with no internet. Change colors, check contrast in the preview and export a ready .json.

Wallpaper by URL

If a theme gives an image address (https://…), the whole theme is a single JSON file. Just send it, and the recipient drops it into the folder.

Wallpaper from a file

For an image on the console, give just the file name, for example wall.jpg, and put the image next to the theme. Keep names unique, for example mytheme-wall.jpg, so themes don't shadow each other.
