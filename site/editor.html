Hover rows to see where each color lands. The preview mirrors the app: a wallpaper behind the store front, a focused card, buttons and the download panel.
Export saves <name>.json. On the console put it — and the wallpaper file, if you used one — into /data/overdrive/themes/, then open Settings → Appearance → Themes in Overdrive and pick it.

Contrast checks follow WCAG 2.1 for normal text (4.5:1) and large text (3:1). Keep canvas, surface and surface2 dark: parts of the app still draw fixed light-on-dark text, so a light theme cannot be read everywhere yet.
